# Namaste React 🚀

## Parcel Use in React

- Dev Server → Runs the React app locally.
- HMR (Hot Module Replacement) → Updates changes without fully refreshing the page.
- Caching → Makes the next build faster.
- File Bundling → Combines project files together.
- Image Optimization → Optimizes images for better performance.
- Minification → Makes code smaller by removing unnecessary characters.
- Code Splitting → Breaks large code into smaller files.
- Tree Shaking → Removes unused code.
